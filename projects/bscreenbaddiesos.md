# Overview

Creation of an operating system with a team of four for the OS Design and Implementation course. Microkernel architecture, based upon the Barrelfish architecture.

We were able to implement a physical memory manager, virtual memory and paging, multi-threading, IPC, and UMP.

OS development gave me an appreciation of the importance of very long design processes and planning. Weeks of planning allowed us to properly implement efficient and original elements into our final project. Our benchmark tests proved we had similar efficiency to non-microkernel operating systems regarding allocation times.
